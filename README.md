# Nature Bella Beauty Salon demo

Mobile-first website concept for Nature Bella Beauty Salon in Khan-Uul, Ulaanbaatar.

This is a private sales demo by anzu, not the salon's official website. Business details were taken from the salon's public Facebook posts and should be confirmed by the owner before launch.

## Included

- Mongolian mobile-first salon presentation
- Verified service categories: hair, nails, skin care, and hair/scalp care
- Call, Messenger, Facebook, and location links
- No fabricated prices, hours, reviews, booking slots, or customer data collection
